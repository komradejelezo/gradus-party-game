# Аудио для ГРАДУСА

Используйте только собственные записи или материалы с правом включения в распространяемую офлайн-игру. Интернет-музыка и чужие записи не подключаются.

Положите MP3 в `public/audio/` и выполните `npm run build`. Отсутствующие слоты автоматически отключены. Приложение не использует синтез речи вместо записи и не выбирает музыку из сети.

| Имя файла         | Назначение                            | Рекомендация                                            |
| ----------------- | ------------------------------------- | ------------------------------------------------------- |
| `menu-theme.mp3`  | Главное меню и создание партии, петля | 90–120 секунд, Nu Disco / Funky House, лёгкий грув      |
| `game-theme.mp3`  | Игровое поле, петля                   | 2–3 минуты, спокойнее меню, без вокала                  |
| `chaos-sting.mp3` | Открытие «Хаоса», однократно          | 1–2 секунды, короткий синтезаторный акцент              |
| `final-theme.mp3` | «Последний градус», петля             | 30–60 секунд, нарастающее ожидание без резкого давления |
| `victory.mp3`     | Экран победителя, петля               | 15–30 секунд, праздничный Electro Swing                 |
| `rules-voice.mp3` | Правила по нажатию, однократно        | Чёткая русская речь, примерно 25–35 секунд              |

Формат: MPEG-1 Layer III, 44,1/48 кГц, 128–192 кбит/с, без тишины в начале и конце петли. Музыка около −18 LUFS, голос около −16 LUFS, пики не выше −1 dBTP. Эти значения — ориентир подготовки, нормализация приложением не выполняется. Держите общий объём небольшим (желательно до 12 МБ): все файлы входят в офлайн-кеш.

Музыка играет на умеренной громкости; при открытой карточке приглушается. Во время голосовых правил музыка дополнительно приглушается. Музыка, эффекты, голос и общий режим тишины управляются отдельно. Браузер может потребовать повторное нажатие после перезагрузки: автоматический запуск до действия пользователя не требуется.

## Текст записанной озвучки

«Добро пожаловать в ГРАДУС! Здесь всё просто. Бросаешь кубик, двигаешь фишку и выполняешь задание по цвету клетки. Справился — получаешь бонус. Облажался — ловишь штраф. Один раз за игру можешь подставить друга! Первым доберись до финиша и пройди последнее испытание. Ну что, готовы? Тогда погнали!»

## Проверка записи

После добавления файлов пересоберите приложение. Включите музыку в меню, повторите голосовые правила, начните партию, откройте «Хаос», финал и победу. Убедитесь, что mute останавливает музыку и голос, переключатели сохраняются, а после офлайн-перезагрузки записи доступны. Удаление любого MP3 с последующей пересборкой не должно мешать игре.
