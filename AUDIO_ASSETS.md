# Аудио для ГРАДУСА

Используйте только собственные записи или материалы с правом включения в распространяемую офлайн-игру. Интернет-музыка и чужие записи не подключаются.

Положите MP3 в `public/audio/` и выполните `npm run build`. Отсутствующие слоты автоматически отключены. Приложение не использует синтез речи вместо записи и не выбирает музыку из сети.

| Имя файла         | Назначение                            | Рекомендация                                            |
| ----------------- | ------------------------------------- | ------------------------------------------------------- |
| `menu-theme.mp3`  | Главное меню и создание партии, петля | 90–120 секунд, Nu Disco / Funky House, лёгкий грув      |
| `game-theme.mp3`  | Игровое поле, петля                   | 2–3 минуты, спокойнее меню, без вокала                  |
| `chaos-sting.mp3` | Открытие «Хаоса», однократно          | 1–2 секунды, короткий синтезаторный акцент              |
| `final-theme.mp3` | «Последний градус», петля             | 30–60 секунд, нарастающее ожидание без резкого давления |
| `victory.mp3`     | Экран победителя, петля               | 15–30 секунд, праздничный Electro Swing                 |
| `rules-voice.mp3` | Правила по нажатию, однократно        | Чёткая русская речь, примерно 25–35 секунд              |

Формат: MPEG-1 Layer III, 44,1/48 кГц, 128–192 кбит/с, без тишины в начале и конце петли. Музыка около −18 LUFS, голос около −16 LUFS, пики не выше −1 dBTP. Эти значения — ориентир подготовки, нормализация приложением не выполняется. Держите общий объём небольшим (желательно до 12 МБ): все файлы входят в офлайн-кеш.

Музыка играет на умеренной громкости; при открытой карточке приглушается. Во время голосовых правил музыка дополнительно приглушается. Музыка, эффекты, голос и общий режим тишины управляются отдельно. Браузер может потребовать повторное нажатие после перезагрузки: автоматический запуск до действия пользователя не требуется.

## Текст записанной озвучки

«Добро пожаловать в ГРАДУС! Тут всё просто. Бросаешь кубик, двигаешь фишку и выполняешь задание. Справился — получаешь бонус. Облажался — ловишь штраф. Один раз за игру можешь подставить друга! Первым доберись до финиша и пройди последнее испытание. Ну что, готовы? Тогда погнали!»

## Проверка записи

После добавления файлов пересоберите приложение. Включите музыку в меню, повторите голосовые правила, начните партию, откройте «Хаос», финал и победу. Убедитесь, что mute останавливает музыку и голос, переключатели сохраняются, а после офлайн-перезагрузки записи доступны. Удаление любого MP3 с последующей пересборкой не должно мешать игре.

## Что действительно готово в версии 2.0

Готовы оригинальные короткие эффекты Web Audio: стеклянный звон, нажатие кнопки, дребезг кубика, шаги фишки, открытие карты, успех, комедийный провал, «Хаос», подстава, финал и короткие победные фанфары. Они описаны в исходном коде синтезатора, не заимствованы из сторонних записей и доступны офлайн. Это звуковые эффекты, а не музыкальный саундтрек.

Полноценные оригинальные музыкальные треки и профессиональные голосовые записи в эту поставку **не включены**. Система воспроизведения готова: четыре музыкальные сцены, плавный переход 420 мс, отдельные уровни музыки/эффектов/голоса, общий mute, приглушение музыки во время голоса и чтения карточки. Без записей отсутствующие файлы не запрашиваются. При скрытии вкладки звук приостанавливается.

## Локальные реплики невидимого ведущего

Мужской голос, ясная дикция, бодрый и дружески дерзкий тон. Без визуального персонажа и без синтеза речи браузера. Записи — отдельные MP3, желательно 1–2 секунды, без музыкальной подложки. Громкость около −16 LUFS, пик до −1 dBTP. Путь — `public/audio/`.

| Файл                | Текст                | Момент                          |
| ------------------- | -------------------- | ------------------------------- |
| `host-start.mp3`    | «ГРАДУС начинается!» | Начало партии                   |
| `host-chaos.mp3`    | «А вот и ХАОС!»      | Открытие карточки «Хаос»        |
| `host-bravo.mp3`    | «Ну ты даёшь!»       | Успех задания с крупным бонусом |
| `host-success.mp3`  | «Засчитано!»         | Успешная дуэль                  |
| `host-failure.mp3`  | «Не прокатило!»      | Проигранная дуэль               |
| `host-sabotage.mp3` | «Подстава!»          | Личная передача задания         |
| `host-final.mp3`    | «Последний градус!»  | Начало финального испытания     |
| `host-victory.mp3`  | «У нас победитель!»  | Победа                          |

Реплики не ставятся в очередь и не накладываются друг на друга. Финал, победа и явно запрошенные правила имеют приоритет. Ведущий не озвучивает каждое нажатие и каждый шаг. Записи `host-*.mp3` независимы: можно добавить лишь часть. `rules-voice.mp3` использует текст выше. Если записи правил нет, игроку предлагается прочитать правила на экране.

## Очередь подготовки аудиоматериалов

1. Четыре полноценных трека: `menu-theme.mp3`, `game-theme.mp3`, `final-theme.mp3`, `victory.mp3` — оригинальные Funky House / Nu Disco / Electro Swing без вокала.
2. Записанные правила `rules-voice.mp3` и восемь реплик `host-*.mp3` из таблицы.
3. При желании — оригинальный `chaos-sting.mp3` вместо уже работающего синтезированного акцента.

Вступление длится 3,8 секунды. До первого касания оно идёт без звука; «Включить звук» запускает звон бокалов и повторяет вступительную последовательность с доступным музыкальным фоном. Без настоящего `menu-theme.mp3` бит не подменяется коротким зацикленным синтезатором. Музыка по умолчанию выключена и включается в настройках. Mute и ранее выбранные настройки сохраняются.
